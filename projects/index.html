CA Trout Fishing Optimizer

  • Built an end-to-end ETL pipeline in Python that scrapes California CDFW trout stocking data, ingests weather and barometric pressure from REST APIs, loading processed data into PostgreSQL on a daily schedule using AWS Lambda with processed data archived to S3.
  • Developed a weighted scoring model which factors stocking recency, water temperature, pressure trends, and cloud coverage to rank optimal fishing locations by day, visualized through an interactive dashboard with maps, rankings, and historical trend visualizations.
